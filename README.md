# Interactive Shopping List

## Description
The Interactive Shopping List is a simple web application that allows users to create and manage a shopping list. Users can add items, enter prices, mark items as purchased, edit existing items, and clear the list.

## Features
- **Add Items:** Enter an item name and price.
- **Mark Purchased:** Mark items as purchased or unmark them.
- **Edit Items:** Change the name and price of an item.
- **Total Cost:** Calculate the total price of purchased items.
- **Clear List:** Remove all items from the shopping list.
- **Local Storage:** Save items so they remain after refreshing the page.

## Technologies Used
- HTML — Structures the webpage.
- CSS — Styles the shopping list.
- JavaScript — Adds interactive features.
- Local Storage — Saves the shopping list in the browser.

## Project Files
- `index.html` — Contains the webpage structure.
- `style.css` — Contains the styling.
- `script.js` — Contains the shopping list functionality.

## How to Run the Project
1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter an item name and price.
5. Click **Add Item** to add it to your list.
6. Use the available buttons to manage your shopping list.
